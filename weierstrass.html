A simplified proof of Weierstrass’s continuous non-differentiable function

Ben Barton-Foskett · October 14, 2026

The proof shown below is a summary of the full proof in the PDF, not a verbatim copy. It is a simplified explanation of Titchmarsh’s proof, included to give an accessible account of how a function can be continuous everywhere and differentiable nowhere.

1. Introduction

Consider the function

W(x) = ∑n=0∞ bn cos(anπx).

We will show that for suitable choices of a and b, this function is continuous for all real x, but has no finite derivative at any point.

2. Prerequisites

The argument uses basic results about convergent sequences and series, continuity, and differentiation.

3. Uniform convergence

A series of functions ∑un(x) converges uniformly to S(x) on an interval if, for every ε > 0, there is an N such that |S(x) − Sn(x)| < ε for every n > N and every x in the interval. Unlike ordinary convergence at a point, the same N works for all x in the interval.

Cauchy criterion

A series ∑ak converges if and only if its partial sums form a Cauchy sequence. Equivalently, for every ε > 0, there is an N such that every tail sum ∑k=nmak has magnitude less than ε when m > n > N.

Weierstrass M-test

Suppose |fn(x)| ≤ Mn for all x, where each Mn is non-negative, and the numerical series ∑Mn converges. Then ∑fn(x) converges absolutely and uniformly.

Indeed, the Cauchy criterion gives a common N for which every tail of ∑Mn is small. For all x, the corresponding tail of ∑fn(x) is bounded by that same tail of ∑Mn. The bound does not depend on x, which gives uniform convergence.

Uniform limit theorem

If continuous functions fn converge uniformly to f, then f is continuous. Given ε > 0, choose N so that fN is within ε/3 of f everywhere. Continuity of fN gives a δ for which |fN(x) − fN(y)| < ε/3 whenever |x − y| < δ. Then

|f(x) − f(y)| ≤ |f(x) − fN(x)| + |fN(x) − fN(y)| + |fN(y) − f(y)| < ε.

4. Continuity of the Weierstrass function

Take 0 < b < 1 and let a be an odd integer greater than 1. Since |cos(anπx)| ≤ 1, for every x and n,

|bn cos(anπx)| ≤ bn.

The geometric series ∑bn converges. The M-test therefore shows that the series defining W converges uniformly. Each term is continuous, so the uniform limit theorem shows W is continuous everywhere.

5. Non-differentiability

The derivative of an individual term is

(bk cos(akπx))′ = −π(ab)k sin(akπx).

The oscillations become faster as k increases, and their slopes have coefficients proportional to (ab)k. When ab > 1 these coefficients grow, suggesting that the difference quotient may be unbounded. We show this for the sufficient condition ab > 1 + 3π/2.

Split the difference quotient

For h ≠ 0 and an integer m ≥ 1, split the difference quotient into low- and high-frequency terms:

[W(x + h) − W(x)] / h = Sm + Rm,

where Sm sums terms with 0 ≤ n < m, and Rm sums terms with n ≥ m.

By the mean value theorem, each cosine difference has magnitude at most πan|h|. Therefore

|Sm| ≤ π∑n=0m−1(ab)n = π((ab)m − 1)/(ab − 1) < π(ab)m/(ab − 1). (*)

Choose h to control the high-frequency terms

Write amx = αm + ξm, where αm is an integer and −1/2 ≤ ξm < 1/2. Choose

h = (1 − ξm)/am,   so   0 < h ≤ 3/(2am). (**)

Thus h tends to zero as m tends to infinity. For n ≥ m, using that a is odd,

cos(anπ(x + h)) = (−1)αm+1,

while

cos(anπx) = (−1)αm cos(an−mπξm).

Consequently the high-frequency tail has one common sign and its terms contain the non-negative factor 1 + cos(an−mπξm). Keeping the first term of the tail gives the lower bound

|Rm| ≥ bm/h ≥ (2/3)(ab)m.

Combine the bounds

Applying |Sm + Rm| ≥ |Rm| − |Sm| and using (*) gives

|[W(x + h) − W(x)]/h| > ((2/3) − π/(ab − 1))(ab)m.

If ab > 1 + 3π/2, the coefficient in parentheses is positive. Since ab > 1, the right-hand side grows without bound as m increases, while (**) gives h → 0. The difference quotient is therefore unbounded near every x, so W has no finite derivative at any point under this condition.
